# 霓虹打磚塊

以 Phaser 3、TypeScript 與 Vite 製作的跨裝置下壓式多球 Roguelite 打磚塊遊戲。

## 玩法

- 磚塊會持續下降；任一磚塊越過紅色警戒線，本局結束。
- 磚塊最低血量為 `max(1, 波數 - 3)`；難易度為 `max(1, 波數 - 6)`；動態血量上限為 `波數² + 難易度²`；最大血量為 `min(血量上限, (波數 + 3) × 難易度)`。
- 球掉落時只移除該球；場上球數低於本局起始球數時，1 秒後自動補足缺少的球並立即發射，遊戲不會暫停。
- 新局開始前會先選擇第 0 波獎勵；每波從永久攻擊力、強化平台、分裂平台、火焰平台、橫桿加長與起始球數中等機率抽出二選一。
- 橫桿最長不得超過畫面寬度的 70%；下一次加長會超過上限時不會出現在獎勵選項中。
- 強化平台讓球的下一次攻擊 +1，可重複穿越疊加。
- 分裂平台會在球完整穿越時產生一顆繼承永久能力的新球。
- 火焰平台使球的下一次攻擊以完整攻擊力穿透飛行方向後方最近的一塊磚，命中後消耗且不疊加。
- 球體顏色會依下一次攻擊力從淺藍逐漸變為深紅。
- 獎勵選擇後可在警戒線以上放置、移動、重疊、收回或刪除平台。

## 本機執行

需要 Node.js 22 或更新版本。

```bash
pnpm install
pnpm dev
```

## 驗證與建置

```bash
pnpm test
pnpm build
pnpm preview
```

## 操作

- 桌機：方向鍵或 A/D 移動；在警戒線以下按住拖曳也能移動橫桿。
- 手機：在警戒線以下按住拖曳控制橫桿。
- 空白鍵、滑鼠點擊或觸碰畫面發球。
- 發球時點擊遊戲區上方，可稍微選擇球往左或往右的方向。
- 點擊 HUD 的球體或平台摘要，可暫停並查看本局能力。

推送至 `main` 後，GitHub Actions 會自動測試、建置並部署到 GitHub Pages。
